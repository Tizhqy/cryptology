# Security Policy

Bu depo egitim ve kontrollu lab deneyleri icindir.

## Kapsam

- Uygulama kodu, config semalari ve deney dokumantasyonu.
- Yalnizca yerel veya yazili izin alinmis test ortamlari.

## Kapsam disi

- Gercek sistemlere yonelik tarama veya saldiri.
- Gercek kimlik bilgileri, private key veya kisisel veri.
- Ucuncu taraf trafik kayitlari.

Bir guvenlik problemi bulursaniz public issue icine secret, exploit payload veya hassas veri koymayin. Once repo sahibine ozel kanaldan bildirin.
