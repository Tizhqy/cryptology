# Wireshark Captures

Gercek `.pcapng` dosyalari bilerek Git'e eklenmez; `.gitignore` tarafindan dislanir. Her capture icin su bilgileri `docs/wireshark` altinda yazin:

- Mod ve key exchange yontemi
- Yakalama yapilan bilgisayar
- Tarih ve test config'i
- Kullanilan display filter
- Dosyanin teslimde nasil paylasildigi

Yalnizca sentetik mesajlar ve test PDF'leri kullanin.
