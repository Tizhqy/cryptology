# Tests

Planlanan test katmanlari:

- `unit`: Domain ve application davranisi
- `integration`: Sunucu, storage ve crypto adapter entegrasyonu
- `contract`: API ve shared protocol sozlesmeleri
- `security`: TLS, auth, integrity, replay, log masking ve insecure profile guard'lari
- `experiments`: Kriptoloji deneyleri ve test vektorleri

Secilecek teknolojiye gore test runner ve CI komutlari burada belgelenecektir.
